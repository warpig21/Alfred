# Alfred brand fonts

Bundled fonts used by the Alfred typography (Fitbill design system).

- **Geist** (`Geist/`) — body / UI font. © Vercel. Licensed under the SIL Open
  Font License 1.1 (see `Geist/OFL.txt`). Source: https://github.com/vercel/geist-font
- **Tex Gyre Heros** (`TexGyreHeros/`) — heading font. © GUST e-foundry.
  Licensed under the GUST Font License (GFL), an LPPL-based license.
  Source: http://www.gust.org.pl/projects/e-foundry/tex-gyre

Body text = Geist; headings = Tex Gyre Heros. Wired in
`lib/workspace/application/settings/appearance/base_appearance.dart`.
